What "fixing it properly"
actually costs.

  • 1.Test fails, retry until it passes.
  • 2.Someone gets bored and investigates.
  • 3.Writes a reproduction script. Can't repro locally. Adds sleeps, mocks, retries.
  • 4.Opens a PR. CI goes green. Merges. Flaky in 3 days.
  • 5.Skip it, create a ticket to unskip it, and ship.
  • 6.Notice in 3 years it's been skipped this whole time, delete it.
  • 7.Repeat.

Across 50+ repos, this compounds. Each flaky test lies to humans and agents trying to iterate against them.

Detection layer — runs every hour via GitHub Actions

One script.
Datadog does the work.

# Query Datadog CI Tests API for known flakes
pup cicd tests search \
  --query '@test.status:fail @test.known_flaky:true \
  --from=1h --limit=50 \
| jq '[.data[].attributes.attributes | {
    repo:  .git.repository.name,
    test:  .test.name,
    file:  "\(.test.source.file):\(.test.source.start)",
    error: .error.message
  }] | group_by(.test, .file)'
Gate 1 — the plan review

I approve plans,
not implementations.

groundcrew runs /flaky-test-debugger in plan mode first. The agent diagnoses the test, proposes a fix strategy, and creates a fix ticket.

I read the plan. If the root cause and fix look right, I set it to Todo. Then groundcrew implements. 

Plan: Fix UserService.findByEmail

Root cause:
  No database cleanup between tests.
  test_a creates user@test.com.
  test_b queries same email,
  finds unexpected record, fails.

Proposed fix:
  1. Add afterEach cleanup block
  2. Use UUID suffix per test email
  3. Verify with --runInBand locally

Estimated change: ~8 lines
Confidence: high

Safety — sandboxed agents

Sandboxes make
yolo modes safer.

Each task gets an isolated git worktree. Agents run in Docker or Safehouse sandboxes.

Auto mode (Claude Code) and Codex's equivalent run without permission prompts, enabling autonomous agents.

  • ✗Can't read/write files outside of where they're started
  • ✗Can't read possible secret-containing env vars
  • ✓Can open PRs and access MCPs
